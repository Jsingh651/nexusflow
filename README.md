# NexusFlow

A modern Kanban board for managing projects and tasks. Built with React, TypeScript, and Vite.

## Features

- Drag-and-drop task management across columns
- Priority levels and task descriptions
- Dark/light theme toggle
- Persistent state via localStorage
- Responsive layout

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
